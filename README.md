# LinuxCLI-python-sed

Projekti harjoituksia Linux-komentoriviltä käyttäen `sed`.

## Hakemistorakenne

- `data/` - lähdeaineistot (kirja.txt, asiakastiedot.txt, log.txt)
- `data/tasks/` - tehtävätiedostot (salattu)
- `configs/` - tallennettu tila (esim. `tila.json`)
- `output/` - generoituja tuloksia (esim. `results.json`)
- `harjoitus.pyc` - CLI/harjoitusohjelma (kompiloidtu)

## Data-tiedostot

| Tiedosto | Kuvaus | Rivejä |
|----------|--------|--------|
| `data/kirja.txt` | Romaaniteksti (Dr. Jekyll & Mr. Hyde, suomeksi) | 3367 |
| `data/asiakastiedot.txt` | 9 asiakasta (nimet, hetut, sähköpostit, IP, puhelimet) | 72 |
| `data/log.txt` | Järjestelmäloki (login/logout, Error, WARNING, INFO) | 27 |
